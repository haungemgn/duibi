# 数据对比工具（Windows 桌面版）

基于原网页《优化数据对页面》重写的原生 Windows 桌面软件。使用 **Python + PySide6 (Qt)**，
性能更高、体验更好，界面与核心逻辑解耦，方便自由优化。

## 功能

完整保留原网页全部功能，并做了增强：

### 集合运算（对 A、B 两组数据，按行处理）
- **重复(A)**：找出 A 中重复出现的元素
- **去重(A)**：A 去重，保持原顺序
- **A−B 差集**：A 有、B 没有
- **A∩B 交集**：A 与 B 共有
- **A∪B 并集**：A、B 合并去重

### 格式化 / 工具
- **AB 互换** / **清空**
- **加逗号** / **加引号逗号**（只格式化，不会隐式去重）
- **去逗号** / **去逗号+单引号** / **去逗号+双引号**
- **JSON 整形**：严格校验后调整缩进和间距，保留数字精度、重复键和字符串转义，并在独立标签页高亮显示
- **复制结果**：一键复制 R 结果到剪贴板

Qt 编辑框会把直接粘贴的段落分隔符（U+2029）当作换行。在 JSON 字符串中请使用转义形式 `\u2029`。

### 选项
- **结果去回车**：结果合并为一行
- **忽略大小写**：集合运算时不区分大小写
- **去首尾空格**：处理时对每行去首尾空格

### 体验增强
- 每个文本框实时显示**行数统计**
- 底部**状态栏**显示 A/B/R 数量与当前操作
- 可拖动的**分割面板**，自由调整 A/B/R 区域大小
- 处理大文本更流畅（QPlainTextEdit）
- **背景切换**：白色 / 灰色 / 黑色三种背景，自动记忆上次选择
- 自动记忆窗口大小、面板比例和处理选项（不会保存输入数据）
- 清空前二次确认，避免快捷键误操作造成数据丢失
- 未处理异常会写入本地日志并显示错误提示，便于排查打包版问题

### 快捷键
| 快捷键 | 功能 |
|--------|------|
| Ctrl+1 | 去重(A) |
| Ctrl+2 | 差集 A−B |
| Ctrl+3 | 交集 A∩B |
| Ctrl+4 | 并集 A∪B |
| Ctrl+R | AB 互换 |
| Ctrl+L | 清空 |
| Ctrl+J | JSON 整形 |
| Ctrl+Shift+C | 复制结果 |

## 运行

### 方式一：直接运行（需已安装 Python）
1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 双击 `运行.bat`，或命令行执行：
   ```bash
   python -m app
   ```

### 方式二：打包成 exe（无需 Python 环境即可分发）
双击 `打包exe.bat`。脚本会检查构建依赖，完成后在 `dist\数据对比工具.exe` 得到单文件程序；发生错误时会保留并显示真实错误信息。

```
│   ├── main.py        # Qt 界面
│   ├── test_core.py   # 核心逻辑测试

├── requirements.txt
├── requirements-dev.txt
├── 运行.bat            # 一键启动
├── 打包exe.bat         # 打包成 exe
└── README.md
```

## 测试
```bash
python -m unittest discover -v
```
